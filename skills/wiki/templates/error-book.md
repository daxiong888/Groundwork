# LLM Wiki Error Book

Target Reader: Wiki maintainers, skill authors, reviewers, and future agent sessions.

Decision Supported: Which wiki failure modes are known, which constraints prevent repeats, and how fixes are verified.
Artifact Type: wiki error book.
Source of Truth: Wiki audits, review findings, source checks, and documented wiki maintenance failures.
Scope: Recurring wiki errors, root causes, constraints, verification methods, and status.
Out of Scope: Full defect tracker, implementation bug database, release approval, UAT approval, runtime proof, browser evidence, customer acceptance, marketplace evidence, installed-plugin evidence, or cache-refresh evidence.
Evidence Level: Wiki maintenance learning only; inspect linked source evidence before using an entry for implementation or verification.
Safe to Share / Redaction Notes: Review entries for secrets, credentials, PII, sensitive logs, private URLs, cookies, tokens, and raw production payloads before sharing.
