# Groundwork Examples

This directory collects maintainer-facing Groundwork case studies.

Formal examples are based on real Groundwork maintenance changes and recorded repository evidence. Draft previews are not counted as real examples until a future PR or release provides complete source, implementation, verification, and handoff evidence.

## Real Maintenance Case Studies

- [`01-scope-first-verification`](01-scope-first-verification/) shows how `verify` was hardened so readiness claims start with explicit scope and evidence instead of overclaiming from partial checks.
- [`02-prototype-contract-boundary`](02-prototype-contract-boundary/) shows how prototype work separates confirmed backend contract facts from mock fields and client-derived display logic.

## Draft / Preview

- [`drafts/03-review-ready-handoff`](drafts/03-review-ready-handoff/) previews a future review-ready handoff case study. It is not counted as a real example yet.
