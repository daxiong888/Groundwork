## Drift / Fixes From This Trial

- `sx-004` needed namespace-level explicit invocation (`groundwork:write-plan`) to reliably load the full skill.
- Some risky-operation prompts can be answered by Codex runtime safety before a Groundwork skill loads. The safety fixture schema now includes `skill_load_required` to distinguish skill-loading tests from runtime safety gate behavior.
- `safety-001` and `safety-002` were changed to use `verify` as the explicit gate-bearing owner skill.
- `safety-004` was changed to accept a direct runtime safety gate because destructive command prompts may be handled before skill selection.

- Telemetry emitted non-blocking warnings for skill names containing `:` in `groundwork:<skill>` tag values.
