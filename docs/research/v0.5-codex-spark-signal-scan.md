## Executive Finding

Spark may be treated as a provisional `spark_iteration` profile for bounded fast coding iteration, not as an unknown model and not as a final review or verification authority.

Supported fit from the branch-local research and review feedback:

```text
- near-instant or low-latency coding iteration
- day-to-day coding tasks
- small scoped edits
- targeted test/edit loops
- interruptible coding tasks
- quota-aware implementation probes
```

The review feedback also concluded that direct Reddit, Hacker News, and OpenAI Community evidence was too sparse to claim representative community consensus. Therefore this scan must not be mandatory for PRD acceptance and must not introduce requirements or acceptance criteria.

## Groundwork Routing Interpretation

Add `spark_iteration` as a provisional profile:

```yaml
spark_iteration:
  model_seed: GPT-5.3-Codex-Spark
  thinking_default: Low or Medium
  use_for:
    - bounded fast coding iteration
    - day-to-day code edits
    - edit/test loops
    - targeted bug fixes with fast reproduction
    - fixture or harness repair with clear failure command
    - quota-aware implementation probe
  evidence_boundary:
    - self-check only unless independently reviewed
    - not final clean review
    - not final verification
    - not public skill approval
    - not release, UAT, marketplace, or customer authority
  escalation:
    - GPT-5.4 for normal completion when Spark stalls or over-edits
    - GPT-5.5 for design uncertainty, high-risk review, or policy decisions
```

## Task Fit Matrix

| Task | Spark fit | Boundary |
| --- | --- | --- |
| Small accepted code edit with fast test | Strong | Self-check only if material. |
| Targeted bug fix with known reproduction | Strong | Must rerun the reproduction command. |
| Fixture/eval harness repair | Strong | Must not create product truth. |
| Prototype code polish | Medium | Contract boundary still applies. |
| Broad refactor | Weak | Route away from Spark by default. |
| Public skill design | Weak | Use stronger design/review profile. |
| Clean review | Weak | Auxiliary pass only; not final authority. |
| Final verification/readiness | Not allowed | Evidence and role separation dominate model choice. |
| Security/privacy/schema/data correctness approval | Not allowed as final authority | Requires high-risk independent review evidence. |

## Local Characterization Needed

Before relying on Spark beyond provisional routing, Groundwork should collect local characterization evidence:

| Case | Prompt shape | Metric | Expected boundary |
| --- | --- | --- | --- |
| spark-small-fix | accepted small bug with failing unit test | latency, patch size, command pass | self-check only; clean review required if material |
| spark-fixture-repair | broken eval fixture or schema fixture | command pass, minimal diff | no product truth creation |
| spark-targeted-regression | one known failing command | original command rerun | no broad refactor |
| spark-prototype-polish | throwaway UI prototype polish | visual packet boundary | no backend contract promotion |
| spark-broad-refactor-negative | broad architecture request | should route away from Spark | no Spark default |
| spark-final-review-negative | user asks Spark to approve high-risk work | block or route to stronger clean reviewer | no final authority |
