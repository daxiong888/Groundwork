# Groundwork v0.1 Review Package

This package freezes `docs/prd.md` as the v0.1 product source of truth and prepares Groundwork for v0.1 tag review.

## Scope

Included:

- Codex plugin manifest: `.codex-plugin/plugin.json`
- Product source of truth: `docs/prd.md`
- Architecture and principle docs aligned to PRD v0.1
- Borrowed source decision log
- Eight shallow public skills under `skills/`
- Required first-cut references: `triage/AGENT-BRIEF.md`, `prototype/LOGIC.md`, `prototype/UI.md`
- Prompt fixtures under `evals/prompts/`
- R&D scenario fixtures under `evals/scenarios/`
- Minimal runtime fixture under `evals/fixtures/minimal-task-search/`
- Spec-level manual baseline
- Local plugin discovery baseline
- Runtime, fixture, and App runtime-safety baselines
- Runtime trial checklist

Not included:

- production-hardened skill behavior
- broad production release thresholds
- marketplace publishing flow
- task CRUD, local task CLI, hooks, MCP server, or app integration
- `OUT-OF-SCOPE.md`, templates, examples, or scripts beyond empty placeholders

## Source Of Truth

`docs/prd.md` is the v0.1 product source of truth.

Supporting docs explain implementation shape and principles, but must not expand MVP scope beyond the PRD. If runtime testing reveals a missing decision, patch `docs/prd.md` before changing skill behavior.

## Runtime Trial Entry Point

Use `evals/runtime-trial-checklist.md` to reproduce or extend runtime trials.

The v0.1 RC trial used a personal marketplace rooted at `/Users/daxiong`, pointing Groundwork to `./.codex/plugins/groundwork`. Future trials should still choose an installation mode first:

1. repo-local plugin from this repository root
2. home-local plugin directory
3. marketplace registration after choosing the target marketplace root

Do not create or update `.agents/plugins/marketplace.json` until the target mode is chosen.

## Review Questions

Reviewers should focus on:

- whether `docs/prd.md` is sufficiently precise to freeze v0.1
- whether the eight public skills are the right surface
- whether trigger contracts are narrow enough to avoid over-triggering
- whether direct fallback is strong enough for small tasks
- whether artifact safety and risky-write gating are strict enough
- whether runtime trial prompts cover the highest-risk behavior
- whether the recorded runtime, fixture, and App safety baselines are sufficient for `v0.1.0`
